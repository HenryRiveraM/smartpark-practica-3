# Preferencias del propietario

- Pedir aprobación explícita del usuario antes de cada commit y antes de cada push o publicación del proyecto en GitHub. Mostrar el destino y resumir los cambios que se publicarán. No interpretar una solicitud de preparación como aprobación para publicar.
- No subir `include/secrets.h`, credenciales, archivos de compilación `.pio/` ni configuración local del editor.
